Sistem Pengecekan Kualitas & Kesesuaian Dokumen Karyawan

Pilih File Excel Template untuk mengecek dokumen dari link Google Drive, atau tambahkan Upload File Dokumen Lokal (JPG/PNG/PDF) jika ingin memeriksa file langsung dari perangkat Anda. Hasil pengecekan akan langsung tampil sebagai report interaktif di halaman web dan dapat diunduh ke Excel.

1. Upload Excel Template (.xlsx / .xls)

Wajib diupload sebagai daftar master karyawan & link dokumen (FORMAT UPLOAD CEK IMAGE.xlsx).

2. Upload File Dokumen / Foto Lokal (Opsional)

Pilih banyak file sekaligus (PDF/JPEG/PNG). Sistem otomatis mencocokkan nama file dengan nama karyawan & jenis dokumen.
